# ระบบเช็คชื่อ & คะแนนเก็บ (Firebase + GitHub Pages)

## ไฟล์ในโปรเจกต์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเข้าสู่ระบบ / สมัครบัญชีนักเรียน |
| `checkin.html` | หน้าที่เปิดขึ้นมาเมื่อนักเรียนสแกน QR |
| `student.html` | นักเรียนดูคะแนนเก็บ กลางภาค ภาระงาน + แจ้งเตือนงานค้าง |
| `teacher.html` | ครู: เปิด QR, เช็คชื่อ, กรอกคะแนน, แจ้งภาระงาน, รายชื่อ |
| `js/config.js` | **ตั้งค่า Firebase, อีเมลครู, รายวิชา/ห้อง** |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~15 นาที)

### 1. สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com → **Add project** → ตั้งชื่อ (เช่น `classcheck`)
2. เมนู **Build → Authentication** → Get started → เปิด **Email/Password**
3. เมนู **Build → Firestore Database** → Create database → เลือก region `asia-southeast1` (สิงคโปร์) → Production mode
4. ⚙️ **Project settings → Your apps → กดไอคอน `</>`** (Web) → ตั้งชื่อ → คัดลอกค่า `firebaseConfig`

### 2. สร้างบัญชีครู
Authentication → **Users → Add user** → ใส่อีเมลครู + รหัสผ่าน
> ⚠️ ต้องสร้างบัญชีครูก่อนเปิดให้นักเรียนใช้

### 3. แก้ไฟล์ตั้งค่า
- `js/config.js` → วาง `firebaseConfig`, แก้ `TEACHER_EMAILS`, แก้ชื่อห้องใน `SECTIONS` (เช่น `ม.3/1`)
- `firestore.rules` → แก้ `'teacher@example.com'` เป็นอีเมลครู (ตรงกับ config.js)

### 4. ใส่กฎความปลอดภัย
Firestore Database → แท็บ **Rules** → ลบของเดิม → วางเนื้อหาจาก `firestore.rules` ทั้งหมด → **Publish**

### 5. อัปขึ้น GitHub Pages
1. สร้าง repository ใหม่ใน GitHub (Public)
2. **Add file → Upload files** → ลากไฟล์ทั้งหมด (รวมโฟลเดอร์ `js`) → Commit
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อคุณ.github.io/classcheck/`

### 6. อนุญาตโดเมน
Firebase → Authentication → **Settings → Authorized domains → Add domain** → ใส่ `ชื่อคุณ.github.io`

## วิธีใช้งาน

**นักเรียน (ครั้งแรก):** เข้าลิงก์เว็บ → สมัครบัญชีด้วยรหัสนักเรียน + ชื่อ นามสกุล ชื่อเล่น + เลือกห้อง

**ทุกคาบ:**
1. ครูเข้า `teacher.html` → เลือกห้อง → **เปิด QR เช็คชื่อใหม่** → กด **เต็มจอ** ขึ้นโปรเจกเตอร์
2. นักเรียนสแกนด้วยกล้องมือถือ → (ล็อกอินครั้งแรก) → กด **ยืนยันเช็คชื่อ**
3. ชื่อเด้งขึ้นตารางครูทันที คนที่ไม่สแกน = **ขาด** · ครูกดเปลี่ยนเป็น มา/สาย/ลา ได้
4. เสร็จแล้วกด **ปิดรับเช็คชื่อ**

**คะแนนเก็บ:** แท็บคะแนนเก็บ → 10 ช่อง × 10 คะแนน + กลางภาค → กด Enter เลื่อนลงแถวถัดไป → **บันทึก**

**ภาระงาน:** แจ้งงาน + กำหนดส่ง → ถ้า "ผูกกับช่องคะแนน" ระบบจะนับว่าใครส่งแล้ว (มีคะแนนในช่องนั้น)
และมีปุ่ม **คัดลอกรายชื่อคนยังไม่ส่ง** ไปวางใน LINE กลุ่ม
ฝั่งนักเรียนจะเห็นแถบเตือนสีแดง (เลยกำหนด) / ส้ม (ใกล้ครบ 2 วัน) และแจ้งเตือนบนมือถือเมื่อเปิดเว็บ

## ระบบกันสแกนแทนกัน
1. **QR เปลี่ยนรหัสทุก 10 วินาที** — ถ่ายรูปส่งให้เพื่อนที่ไม่อยู่ในห้อง รหัสจะหมดอายุก่อน
2. **1 เครื่อง = 1 บัญชี ต่อคาบ** — ล็อกเอาต์แล้วล็อกอินบัญชีเพื่อนในเครื่องเดิมจะเช็คไม่ได้
3. **ต้องล็อกอินบัญชีตัวเอง** — เช็คชื่อได้เฉพาะตัวเอง และเฉพาะห้องที่ลงทะเบียนไว้
4. นักเรียน **อ่านรหัส QR จากฐานข้อมูลไม่ได้** (กฎ Firestore บล็อกไว้)
5. หน้ายืนยันแสดงชื่อ-ชื่อเล่นตัวใหญ่ ครูเดินดูได้ + ตารางครูบอกว่าสแกนหรือครูกรอกเอง

> ข้อจำกัด: ถ้านักเรียนยืมมือถือเพื่อนที่ **ยังไม่ได้เช็คชื่อ** หรือใช้โหมดไม่ระบุตัวตนเพื่อเปลี่ยนเครื่อง ยังพอทำได้ — ครูนับจำนวนคนในห้องเทียบกับตัวเลข "สแกนแล้ว" บนจอเต็มจอได้

## คำถามที่พบบ่อย
- **นักเรียนลืมรหัสผ่าน:** Firebase → Authentication → Users → ลบบัญชีนั้น → ให้นักเรียนสมัครใหม่ด้วยรหัสเดิม (ข้อมูลคะแนนเดิมจะไม่ผูก ต้องกรอกช่องคะแนนใหม่ — หรือเก็บไว้ก่อนด้วยปุ่ม CSV)
- **ขึ้นเทอมใหม่:** ในรายชื่อนักเรียนกด "เอาออกจากห้อง" หรือสร้าง Firebase project ใหม่
- **ค่าใช้จ่าย:** แผน Spark (ฟรี) เพียงพอสำหรับ 6 ห้อง
